# convergence-interaction-studies

Six interactive plates (levels 00 to 05) built as Claude artifacts, kept as studies of interactive storytelling to borrow from when building the Convergence website. These are not part of the site. Nothing here is imported by DyloFi/convergenceweb.

**The overall theme comes from the baseline and Convergence II pages, not from these.** The baseline is DyloFi/convergenceweb at tag baseline-2026-10-18, and Convergence II is public/convergence-ii.html on main. Everything below is secondary to those two.

| Entry | What it is |
| --- | --- |
| interactive-plates/ | Secondary. The six interactive plates, levels 00 to 05, exported from Claude artifacts. Interaction reference only. |
| interactive-plates/loar-level01/ | Level 01, The Law of Accelerating Returns: the pinned scroll-driven plate, with its own notes. |

Each folder has its own README: what it is, how it works, what to reuse, what is content-specific, and what has not been verified.

Rule: files in an entry are byte-identical to the original export. Notes go in the README, never in the original files.
