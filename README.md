# convergence-references

Reference examples of interactive storytelling and interaction design, kept to draw from when building the Convergence website. These are not part of the site. Nothing here is imported by DyloFi/convergenceweb.

**The overall theme comes from the baseline and Convergence II pages, not from these.** The baseline is DyloFi/convergenceweb at tag baseline-2026-10-18, and Convergence II is public/convergence-ii.html on main. Everything below is secondary to those two.

| Entry | What it is |
| --- | --- |
| interactive-plates/ | Secondary. Five interactive plates (levels 00, 02, 03, 04, 05) exported from Claude artifacts. Interaction reference only. |
| loar-level01/ | Secondary. Pinned scroll-driven plate: The Law of Accelerating Returns, Level 01. This is the Level 01 plate in the set. |

Each entry has its own README: what it is, how it works, what to reuse, what is content-specific, and what has not been verified.

Rule: files in an entry are byte-identical to the original export. Notes go in the README, never in the original files.
