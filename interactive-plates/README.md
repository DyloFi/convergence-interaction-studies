The six interactive plates from the Convergence Claude artifacts, kept here as studies of interactions to borrow later. Level 01 is in loar-level01/loar-level01.html, byte-identical to the export.

**Secondary.** The overall theme for the Convergence site is the baseline (DyloFi/convergenceweb, tag baseline-2026-10-18) and the Convergence II page (public/convergence-ii.html on main). These plates do not set the look of the site. Their colour, dense text and figure labels break the design spec (zero text, zero colour, layout alone carries mood). Borrow their interaction mechanics, not their styling.

## What it is
Standalone HTML exports of Claude artifacts, saved 19 Oct 2026. Each file is byte-identical to the original export on the Mac. Do not edit the HTML; copy a file to work on it, and put notes in this README.

## How they work
Each file is self-contained, with inline CSS and JavaScript. The only outside load is Google Fonts, so a page looks plainer offline but still runs. They have not been opened on a phone or traced in detail here.

## What to reuse
Interaction patterns such as pinned scroll stages, dial and timeline drags, tab and play controls, and drawers that open source files. Where a plate's mechanics are clear, note them in this README before reusing.

## What is content-specific
All text, figures, sheet drawings and the year labels. Level 03 and Level 04 carry research figures that are marked unverified.

## What has not been verified
Whether each plate works on a phone, whether the interactions are complete, and whether any of them break without a network connection. These were served from a local preview on 19 Oct 2026, and the preview only checked HTTP 200 responses and file sizes.
