## Read the ramp

GRID LINE A

ASHEET 01.A · GRID LINE A · EL. +24.000

### Where intuition stops

Most of us expect progress to behave like a ramp: a steady slope, the same distance gained each year. The Law of Accelerating Returns, set out by Ray Kurzweil in 2001 and 2005, says the slope itself steepens.

Technology compounds. The output of one generation is reused as an input to design, simulate and manufacture the next, so each generation arrives faster than the last. The research files state the strongest form of the claim: not merely exponential growth, but a growth rate that itself grows.

Linear intuition adds. This claim multiplies.

BSHEET 01.B · GRID LINE B · EL. +25.500

### The feedback loop

Better hardware runs better design software. Better software draws denser chips. Denser chips need better fabrication and materials, and those produce better hardware. The loop closes on itself.

The repository formalizes this as a double-exponential. It is a model of a mechanism, not a measurement of it, and the drawing treats it that way.

Model, not measurement.

### Five paradigms and a staircase

The evidence is a staircase, not a line. The files trace computation per dollar through five physical paradigms: electromechanical tabulators, relays, vacuum tubes, discrete transistors and integrated microprocessors, from Hollerith-era machines to 2026 hardware. Each paradigm climbs quickly, then flattens, and the next one picks up the climb.

DSHEET 01.D · GRID LINE D · EL. +28.500

### The limits at the tip

Every paradigm meets a wall. The files list the physical ones: the end of Dennard scaling around 2005, which created the power wall; Landauer’s thermodynamic floor for erasing a bit; and Amdahl’s limit on parallel speedup. Economists add their own: Nordhaus’s productivity test, Gordon’s stagnation thesis, Cowen’s low-hanging fruit.

The honest reading is that the curve is an envelope of S-curves. It continues only while the next paradigm arrives on time. The files name a sixth: three-dimensional transistors, photonics, neuromorphic and quantum chips. Whether it arrives is the open question, and at the tip the ramp becomes an asymptote, the doorway to the Singularity dossier.

The ramp ends where the next paradigm must begin.
